# Rewrite Profile README

1. Ask the user for tone preferences and what to emphasize.
2. Pull repo details (languages, top projects, recent activity) via the GitHub MCP.
3. Draft an authentic, non-generic README that reflects the user's genuine voice and actual work.
4. Open a draft PR with the changes (clear title + a summary of what changed and why).
